# READY SPACE

React 19과 Vite 기반의 반응형 브랜드 웹사이트입니다.

## 실행

```bash
npm install
npm run dev
```

## 라우트

- `/` — Planet landing page
- `/config` — Process and configuration
- `/portfolio` — Live project portfolio
- `/awards` — Awards and milestones

프로덕션 빌드는 `npm run build`로 생성합니다. 배포 서버에서는 모든 라우트를 `index.html`로 연결하는 SPA fallback 설정이 필요합니다.
